# Pujita Nagalakshmi Kotha — Portfolio

A personal portfolio built with React, Vite, Tailwind CSS, Framer Motion, and smooth scrolling effects.

## Getting Started

Install dependencies and start the dev server:

```bash
npm install
npm run dev
```

## Available Scripts

```bash
npm run dev
npm run build
npm run preview
npm run lint
```

## Tech Stack

- React
- Vite
- Tailwind CSS
- Framer Motion
- react-scroll-parallax
- react-scroll
- react-icons

## Deployment

This project is ready to deploy as a standard Vite app on platforms like Vercel or Netlify.
